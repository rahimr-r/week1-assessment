
# Week 1 Assessment: Git, Terminal and Notebook

## Project Overview

This project analyzes employee data using Python and Pandas. It demonstrates Git version control, terminal commands, Jupyter Notebook analysis, and notebook export using nbconvert.

## Project Structure

- `data/cities.csv` — Employee dataset.
- `notebooks/city_analysis.ipynb` — Jupyter Notebook analysis.
- `src/city_analysis.py` — Exported Python script.
- `reports/findings.md` — Analysis findings report.

## Setup Instructions

1. Clone the repository.
2. Install dependencies using `python -m pip install pandas notebook nbconvert`.
3. Start Jupyter Notebook using `python -m notebook`.
4. Open `notebooks/city_analysis.ipynb`.
5. Run the notebook cells from top to bottom.

## Key Findings

1. The dataset contains 8 employees and 4 columns.
2. No missing values were found in the dataset.
3. Three employees belong to Chennai.
4. The overall average salary is ₹39,000.
5. Bangalore has the highest city-wise average salary at ₹46,000.
